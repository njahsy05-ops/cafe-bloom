# Café Bloom

Café Bloom är en responsiv webbplats för ett fiktivt café. Webbplatsen är skapad som ett studentprojekt.

## Innehåll

Webbplatsen består av fyra sidor:
- Startsida
- Meny
- Om oss
- Kontakt

## Funktioner

- Responsiv design för mobil och desktop
- Navigationsmeny
- Kontaktformulär med validering
- Felmeddelanden vid tomma eller felaktigt ifyllda fält
- Bilder med alt-texter
- Semantisk HTML

## Tekniker

Projektet är byggt med:
- HTML
- CSS
- JavaScript
- Vite

## Validering

Webbplatsens HTML-sidor har kontrollerats med W3C Markup Validation Service.
