# Café Bloom

Café Bloom är en responsiv webbplats för ett fiktivt kvarterscafé i Skövde. Webbplatsen är skapad som ett studentprojekt i kursen DT224G.

**Publicerad webbplats:** https://njahsy05-ops.github.io/cafe-bloom/

## Sidor

- `index.html` – Startsida
- `meny.html` – Meny med filter per kategori
- `om-oss.html` – Om caféet
- `kontakt.html` – Kontaktuppgifter, öppettider och kontaktformulär

## Mappar

- `css/` – stilmall
- `js/` – JavaScript
- `images/` – bilder och logotyp
- `design/` – wireframes (mobil och desktop) och mockup från Figma

## Funktioner

- Responsiv design för mobil och desktop
- Mobilmeny som öppnas och stängs med JavaScript
- Kontaktformulär som valideras med JavaScript, med felmeddelanden
- Filtrering av menyn efter kategori
- Semantisk HTML och alt-texter på bilder

## Tekniker

HTML, CSS och JavaScript utan ramverk.

## Validering

Alla HTML-sidor har kontrollerats med W3C Markup Validation Service utan fel.

## Branches

- `dev` – löpande utvecklingsarbete
- `main` – version som är redo att publiceras
